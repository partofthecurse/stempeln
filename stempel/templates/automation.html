BEISPIELE

So sprichst du die API an

POST {{ base_url }}/api/v1/clock mit Header Authorization: Bearer <token> und JSON {"action": "…"}. Mögliche Aktionen:

  • in / out / toggle – ein- oder ausstempeln, z. B. per NFC-Tag am Schreibtisch.
  • Optional "project": "Name" oder die Projekt-ID: in/toggle mit Projekt startet dieses Projekt; läuft gerade ein anderes, wird gewechselt. So kann jeder NFC-Tag ein eigenes Projekt haben.
  • heartbeat – „ich arbeite gerade“. Startet bei Bedarf eine Sitzung; bleiben die Signale länger als die Leerlaufzeit aus, wird automatisch ausgestempelt.

GET {{ base_url }}/api/v1/status liefert Status, heutige Nettozeit und Saldo (z. B. für ein Home-Assistant-Dashboard).

Mit ?format=text antwortet Stempel nur mit einem lesbaren Satz, z. B. „✅ Eingestempelt um 08:12 · heute 0:00 h von 8:00 h“. Ideal für Handy-Mitteilungen. Im JSON steht derselbe Text im Feld message.

NFC-Tag mit dem iPhone (Kurzbefehle)
  1. Kurzbefehle → Automation → + → NFC → Tag scannen, „Sofort ausführen“ wählen.
  2. Aktion „Inhalte von URL abrufen“: URL {{ base_url }}/api/v1/clock?format=text&action=toggle, Methode POST, Header Authorization = Bearer stp_….
  3. Aktion „Mitteilung anzeigen“ mit dem Ergebnis „Inhalte der URL“.
NFC-Tag mit Android
  1. Mit Home Assistant: In der Companion-App unter Einstellungen → Tags einen Tag beschreiben, dann eine Automation mit Auslöser „Tag gescannt“ und Aktion rest_command.stempel mit action: toggle anlegen (siehe unten).
  2. Ohne Home Assistant: In der App „HTTP Shortcuts“ einen POST auf {{ base_url }}/api/v1/clock?format=text&action=toggle mit dem Authorization-Header anlegen, „Antwort als Toast anzeigen“ wählen und den Shortcut mit „NFC Tools“ auf den Tag schreiben.
curl
curl -X POST {{ base_url }}/api/v1/clock \
  -H "Authorization: Bearer stp_…" -H "Content-Type: application/json" \
  -d '{"action": "toggle"}'
Home Assistant (rest_command + Automation)
# configuration.yaml
rest_command:
  stempel:
    url: "{{ base_url }}/api/v1/clock"
    method: post
    headers:
      Authorization: !secret stempel_token   # "Bearer stp_…"
    content_type: "application/json"
    payload: '{"action": "{{ '{{' }} action {{ '}}' }}"}'

# Automation: Arbeits-PC an/aus (z. B. über HASS.Agent, Ping- oder Steckdosen-Sensor)
triggers:
  - trigger: state
    entity_id: binary_sensor.arbeitslaptop
actions:
  - action: rest_command.stempel
    data:
      action: "{{ '{{' }} 'in' if trigger.to_state.state == 'on' else 'out' {{ '}}' }}"
